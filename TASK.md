# Replay system (Full documentation available in docs/ReplaySystem.md)
Use playwright test to verify your progress - it will simulate a game player session with a replay system. Make sure to keep replay system working, even after you add scenes. The Replay System works by simulating actions (derived from keypresses, no mouse clicks) per fixed time simulation tick (60hz) and after each action a screenshot is taken. Playwright will compare actual screenshots with expected screenshots generated by the C code. All replays start with the main menu and navigate from there. I suggest following replay order:
1. main-menu.spec.ts
2. monologue.spec.ts
3. go.spec.ts
4. from-start-to-finish-first-burglary.spec.ts

You can use tools/replay_dump gamedata/<name>.rec to inspect replay content as text.
